# MySeed Cloudstream

إضافة Cloudstream لموقع [MySeed](https://m.myseed.tv/). تدعم الصفحات الرئيسية، البحث، الأفلام، والحلقات، وتستخرج سيرفرات المشاهدة الموجودة في صفحة MySeed.

تقرأ الإضافة كل الجودات المتاحة في صفحة المشاهدة. وبما أن الموقع يعيد معرّفات السيرفرات أولًا ولا يرسل رابط التشغيل إلا بعد طلب ثانٍ، تطلب الإضافة رابط كل سيرفر على حدة قبل تمريره إلى Cloudstream.

## رابط المستودع داخل Cloudstream

```text
https://raw.githubusercontent.com/AbanobAshrafWilliam/MySeed-Cloudstream/builds/plugins.json
```

> استخدم الإضافة فقط مع المحتوى الذي تملك حق الوصول إليه، واحترم قوانين بلدك وحقوق أصحاب المحتوى.
